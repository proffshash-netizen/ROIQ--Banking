# ROIQ AI Backend – API Specification

## Overview
The backend is a **FastAPI** application located in the `backend/` directory of the repository. All API contracts that the frontend expects are defined in the individual router modules under `backend/routers/`.

## Where the endpoints are defined
| Router file | Base URL (mounted in `main.py`) | Endpoints (relative to base) |
|-------------|--------------------------------|------------------------------|
| `routers/dashboard.py` | `/api/v1/dashboard` | `GET /overview` – returns `DashboardResponse` (protected by JWT) |
| `routers/auth.py` | `/api/v1/auth` | `POST /login` – returns JWT and user info (public) <br> `GET /me` – returns current user payload (protected) |
| `routers/external_data.py` | `/api/v1/external-data` | `POST /normalize` – fetch external data and normalize into the AI contract |
| `routers/health.py` | `/api/v1/health` | `GET /health`, `GET /ready`, `GET /live` – app health probes |
| `routers/stream.py` | `/api/v1/stream` | `GET /` – SSE placeholder |
| `routers/websocket.py` | `/api/v1/ws` | WebSocket placeholder |

## New external data pipeline
This backend now implements an external data ingestion and normalization pipeline via `POST /api/v1/external-data/normalize`.

The route is designed to:
- fetch external financial, market, macro, and legal/ESG data
- normalize heterogeneous provider responses into a consistent internal contract
- return a validated payload for the downstream AI system

### Important placeholder guidance
- Do not hard code any external API keys in source control.
- Use `backend/.env.example` as a placeholder template.
- Copy it to `backend/.env` and replace values with private API keys shared separately.

## Data models
All response models are defined in `backend/models.py`. The most important ones for the current frontend are:
- **DashboardKPIs** – matches the `DashboardState` used by Zustand.
- **UploadResponse** – status and generated `datasetId`.
- **User** – minimal user information returned by `/auth/me`.
- Placeholder models (`AnalyticsData`, `ForecastData`, `RiskData`, `ReportData`, `InsightsData`) are present for future implementation.

## How to run the backend
```bash
# Clone the repository and cd into the project root
git clone <repo‑url>
cd roiq-ai-frontend

# Install backend dependencies (Python 3.11+ recommended)
python -m venv .venv
. .venv/Scripts/activate   # Windows
pip install -r backend/requirements.txt

# Run the server (development mode)
uvicorn backend.main:app --reload
```
The API will be reachable at `http://127.0.0.1:8000`. Swagger UI is available at `http://127.0.0.1:8000/docs`.

## Documentation for the backend team
- **Endpoint definitions** – see each router file under `backend/routers/`.
- **OpenAPI schema** – automatically generated by FastAPI; viewable via `/docs` or `/openapi.json`.
- **Authentication** – JWT based, implemented in `backend/auth.py`. The frontend sends the token in the `Authorization: Bearer <token>` header; the `get_current_user` dependency enforces it.
- **CORS** – configured in `backend/main.py` to allow `http://localhost:5173` (adjust for production).

---
*All UI code already consumes these endpoints via the service layer in `src/services/`. No changes to components or routing are required once the backend is live.*
